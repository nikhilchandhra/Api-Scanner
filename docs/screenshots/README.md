# Screenshots

Drop your screenshot PNGs in this folder so they render inline in the main
[`README.md`](../../README.md). The main README references these filenames:

| Filename | What to capture |
|---|---|
| `index.png` | The project picker (home page) with a path entered and the Recent Projects list. |
| `dashboard.png` | The dashboard showing controller groups and a couple of expanded endpoint cards. |
| `api_detail.png` | A single endpoint — payload editor, response example, and a Try it out result. |

## How to capture

1. Run the app (`python scanner.py`) and scan a sample Spring Boot project.
2. Use your OS screenshot tool:
   - **Windows:** `Win` + `Shift` + `S`
   - **macOS:** `Cmd` + `Shift` + `4`
   - **Linux:** your desktop's screenshot utility
3. Save each image here with the exact filename from the table above.

PNG is recommended. Keep the width reasonable (around 1200–1600px) so the images
load quickly on GitHub.
